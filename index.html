Enterprise Performance Validation Made Simple

SimpliLoad is a performance and load testing utility built specifically for IBM Cognos Analytics environments. It empowers BI administrators and infrastructure teams to validate server capacity, optimize environments, and confidently plan system upgrades.

Production deployments: SimpliLoad is officially distributed through the Azure Marketplace as a managed VM offering.

Evaluation: A local trial build is available for developers who wish to explore SimpliLoad before deploying in Azure.

Compatibility: SimpliLoad requires IBM Cognos Analytics version 12.1.3 or later, as earlier versions do not provide the REST API endpoints used for report execution.

Key Capabilities

  • Azure-Managed Deployment: Runs inside your dedicated Azure VM, giving you full control over network boundaries, firewall rules, and operational security.
  • Enterprise Security: Supports both organization-issued TLS certificates and automatically generated self-signed certificates, allowing you to enforce your internal security standards.
  • REST API Native: Built specifically for IBM Cognos Analytics 12.1.3 and later, using the official REST API for accurate, reliable report execution and performance measurement.
  • Streamlined Configuration: Configure SimpliLoad entirely through its web interface using only your Cognos REST API URL and API key—no additional credentials or namespaces required.
  • Isolated Workloads: Each deployment operates within your own Azure subscription, ensuring that test activity remains fully isolated from other environments and workloads.
  • Performance & Capacity Insights: Identify bottlenecks, validate infrastructure readiness, and simulate real-world Cognos workloads to support upgrade planning and environment optimization.
  • Rapid Setup: Designed for minimal deployment friction—provision the VM, configure your REST API connection, and begin testing within minutes.

Download Trial Bundle (.zip) SHA256 Checksum

Verify File Integrity: Download both files to the same directory and run the command for your OS:

  • Windows (PowerShell): Get-FileHash simpliload-trial.zip -Algorithm SHA256
  • Linux / macOS: sha256sum -c simpliload-trial.zip.sha256

Getting Started: Once verified, extract the archive and open the included SimpliLoad Deployment Guide.pdf for step-by-step setup instructions.
