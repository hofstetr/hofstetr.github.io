Overview

SimpliLoad is a performance and load testing utility built specifically for IBM Cognos Analytics environments.

It empowers BI administrators and infrastructure teams to validate server capacity, optimize environments, and confidently plan system upgrades.

Key Capabilities

  • Azure-Managed Deployment

    Runs inside your dedicated Azure VM, giving you control over network boundaries, firewall rules, and operations.

  • Enterprise Security

    Supports organization-issued TLS certificates or automatically generated self-signed certificates.

  • Native REST API

    Built for IBM Cognos Analytics 12.1.3 and later using the official REST API.

  • Streamlined Configuration

    Configure SimpliLoad with only your Cognos REST API URL and API key.

  • Isolated Workloads

    Deploy in your own Azure subscription and keep test activity separate from production workloads.

  • Performance & Capacity Insights

    Identify bottlenecks, validate infrastructure readiness, and simulate real-world Cognos workloads.

  • Rapid Setup

    Provision the VM, configure your connection, and begin testing within minutes.

Compatibility

Requires IBM Cognos Analytics version 12.1.3 or later.

Verify your download

Download the SHA256 checksum alongside the trial bundle, then verify the ZIP before extracting it:

  • Windows (PowerShell): Run Get-FileHash .\simpliload.zip -Algorithm SHA256 and compare the result with the downloaded checksum file.
  • Linux / macOS: Keep both files in the same directory and run sha256sum -c simpliload.zip.sha256.
