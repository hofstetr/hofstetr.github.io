SimpliLoad Azure Deployment Guide

Overview

SimpliLoad is a lightweight, Docker-based utility that enables IBM Cognos Analytics users to run reports through the REST API using a clean, modern interface. This guide explains how to deploy SimpliLoad using the Azure Marketplace offering, including VM provisioning, configuration, access, and connectivity to Cognos Analytics.

Prerequisites

IBM Cognos Analytics

SimpliLoad requires IBM Cognos Analytics 12.1.3 or later. Earlier versions are not supported because required REST API endpoints are unavailable.

Azure Requirements

  • An active Azure subscription
  • Permission to create virtual machines, networking resources, and public IP addresses

User Requirements

  • Cognos REST API URL
  • Cognos API key
  • Ability to configure firewall rules if Cognos is hosted on-prem or behind a VPN

Deployment Steps in Azure Portal

1. Start the Deployment

Open the Azure Marketplace listing for SimpliLoad, select the desired plan, and click Create to begin the deployment wizard.

2. Basics

Fill out the standard Azure VM fields:

  • Subscription
  • Resource Group
  • Region
  • VM Name
  • Authentication Type
  • Administrator Account

VM Size

  • Trial Plan: D2s_v4 only
  • Single and Unlimited Plans: D2s_v4, D4s_v4, or D8s_v4

3. TLS Certificate Options

Organization-Provided Certificate

If your organization requires certificates signed by an internal or enterprise CA, you may upload a certificate during deployment. SimpliLoad will install and use this certificate for HTTPS.

Automatically Generated Self-Signed Certificate

If no certificate is provided, SimpliLoad automatically generates a self-signed certificate. Browsers may display a warning until the certificate is trusted locally.

4. Networking

Configure networking options:

  • Virtual Network
  • Subnet
  • Public IP
  • Network Security Group rules:
    • Allow HTTPS (443)
    • Allow SSH (22) if VM access is needed

5. Review + Create

Azure will validate your configuration. Click Create to begin deployment.

Post-Deployment Steps

Accessing SimpliLoad

SimpliLoad enforces an allowed-hosts list for security. During deployment, the VM's hostname is automatically added to ALLOWED_HOSTS. The public IP address is not added by default, so accessing SimpliLoad using the raw IP will be rejected unless you explicitly allow it.

If your organization prefers to access SimpliLoad using the public IP, you may add it manually using the Optional Additional Allowed Hosts parameter during deployment.

Most customers will access SimpliLoad using the fully qualified hostname shown in the VM's Overview page, for example:

https://simpliload-prod.eastus.cloudapp.azure.com/

Logging Into the VM (Optional)

SSH access is available if needed:

ssh <admin-user>@<hostname>

Docker containers are located under:

/opt/simpliload/

Connecting to Cognos

All Cognos configuration is performed inside the SimpliLoad UI.

On the Settings page, enter:

  • Cognos REST API URL
  • API Key

Click Test to verify connectivity. No additional credentials or namespace fields are required.

Updating SimpliLoad

To update SimpliLoad:

docker compose pull
docker compose up -d

Troubleshooting

Cannot reach SimpliLoad

  • Ensure you are using the hostname, not the public IP
  • Confirm port 443 is open
  • Verify the TLS certificate is valid

Cannot connect to Cognos

  • Confirm Cognos is version 12.1.3+
  • Verify the REST URL
  • Check firewall rules
  • Validate the API key

Docker container not running

docker ps
docker logs simpliload
